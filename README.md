# GitHub 协作实操练习场

这是一个与正式项目完全隔离的个人练习仓库，用来亲手走完：

`修改 → 查看差异 → 暂存 → 提交 → 推送 → Pull Request → 审核 → 合并 → 解决冲突`

## 从这里开始

1. 阅读 [`GitHub协作实操手册.md`](GitHub协作实操手册.md)。
2. 按“第一次完整 PR”章节操作，不要直接在 `main` 上写练习答案。
3. 完成正常 PR 后，再做“人为制造并解决冲突”。

预计首次完整练习需要 45-70 分钟。

## 完成检查

- [ ] 能说清 `main`、`origin/main` 和 `HEAD` 的区别
- [ ] 能识别 `U / M / A / D / R` 文件状态
- [ ] 能在 VS Code 中查看 diff、暂存、取消暂存和提交
- [ ] 能创建分支、Push 并在 GitHub 创建 PR
- [ ] 能看懂 Source Control Graph 的分叉与汇合
- [ ] 能使用三方合并编辑器解决一次冲突

> 正式项目 [`moose-djy/dc-survival-guide`](https://github.com/moose-djy/dc-survival-guide) 不参与本练习。
